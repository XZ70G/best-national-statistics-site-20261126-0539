Australia by the Numbers — a national statistics site for Australia. The headline figures from the Australian Bureau of Statistics (population, economy, labour market and prices), each with its source and period, on pages reached by links, with charts drawn by the site's own code. Static files only: no network requests, no tracking, no account.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — overview, population, economy, labour market and prices pages, plus a sources page listing every ABS release behind the figures.
